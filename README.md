# Proyect:

**RetroPVPArena** es una plataforma que busca dar lugar a viejos jugadores empedernidos.
Es una **plataforma multifunción** en la que puedes organizar y participar en torneos retro,
asi como tener acceso a material de otra epoca a traves de nuestra tienda perdida en el tiempo.

**Aporte del desarrollo:**

- Desarrollo **front end** que cubre una pagina web funcional, para dar info y acceso a clientes.
- Desarrollo **back end** donde centralizamos toda la gestión interna de la plataforma.
- **BBDD** para tener un registro y persistencia, rankings, ventas, usuarios...

# Stack Tecnologico

- **Front:** HTML5, CSS3, ¿¿JS?? ¿Debería si no lo hemos dado?, JavaFX

- **Back:** Java 17+, JDBC, Maven

- **BBDD:** MariaDB, SQL

- **Otros:** Desplegar en Docker BBDD
